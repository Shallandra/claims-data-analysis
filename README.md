# Claims Data Analysis Dashboard

This project analyzes a structured claims dataset using Excel to identify key trends, cost drivers, and operational patterns.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization (Charts)

## Key Insights
- Identified high-cost claim categories driving overall expenses  
- Analyzed approval and denial rates to understand claim outcomes  
- Evaluated monthly claim trends to identify patterns in volume  

## Project Overview
The dashboard includes:
- Claim cost analysis by type  
- Claim status breakdown (approved, denied, pending)  
- Monthly trend analysis  

This project demonstrates foundational data analysis skills, including data cleaning, aggregation, and insight generation.
